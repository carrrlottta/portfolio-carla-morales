# Aplicación web de arriendo de inmuebles con Django

Proyecto formativo desarrollado con **Python, Django y PostgreSQL**.

## Objetivo

Construir una aplicación web que permita gestionar y consultar inmuebles disponibles para arriendo,
considerando distintos tipos de usuario y una estructura geográfica basada en regiones y comunas.

## Funcionalidades demostradas

- Autenticación de usuarios: registro, inicio y cierre de sesión.
- Perfiles diferenciados para arrendadores y arrendatarios.
- Gestión de permisos y acceso a funcionalidades según rol.
- Creación, edición y eliminación de inmuebles.
- Consulta de oferta disponible.
- Administración de regiones, comunas y tipos de inmueble.
- Persistencia en PostgreSQL.
- Uso de Django ORM.
- Reportes y filtrado por comuna y región.

## Tecnologías

- Python
- Django
- PostgreSQL
- Django Auth
- Django ORM
- HTML
- CSS
- Git
