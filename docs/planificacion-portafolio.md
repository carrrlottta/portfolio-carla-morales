# Planificación y buenas prácticas del portafolio

Este documento reúne la planificación de la etapa anterior y deja evidencia de que fue incorporada
en la implementación del portafolio.

## Repositorio seleccionado: GitHub

Se eligió GitHub porque permite:

- Control de versiones con Git.
- Repositorios públicos accesibles para reclutadores y docentes.
- Documentación mediante archivos README.
- Historial visible de cambios.
- Publicación gratuita de sitios estáticos mediante GitHub Pages.
- Integración directa entre el código fuente y el portafolio publicado.

## Objetivo del portafolio

Presentar de forma clara y profesional la experiencia, habilidades técnicas y proyectos de Carla
Morales Pacheco, con foco principal en desarrollo iOS y una muestra complementaria de desarrollo web.

## Buenas prácticas aplicadas

1. **Objetivo claro:** el sitio está orientado a reclutadores y evaluadores técnicos.
2. **Selección de trabajos:** se incorpora un proyecto que evidencia habilidades técnicas concretas.
3. **Diseño atractivo y simple:** jerarquía visual clara, navegación corta y contenido legible.
4. **Información clara y concisa:** cada sección tiene una función específica.
5. **Responsive design:** el portafolio se adapta a escritorio, tablet y móvil.
6. **Accesibilidad básica:** etiquetas semánticas, texto alternativo y enlace para saltar al contenido.
7. **Optimización:** no requiere frameworks ni librerías externas; los recursos son livianos.
8. **Actualización:** la estructura permite sumar nuevos proyectos sin rediseñar todo el sitio.
9. **Contacto visible:** GitHub, LinkedIn y correo están disponibles desde el inicio y el cierre del sitio.
10. **Evidencia técnica:** cada proyecto puede incluir ficha, capturas, informe y enlace a su repositorio.
